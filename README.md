# Code2UML 📐

Сучасний веб-додаток для автоматичної генерації академічних блок-схем алгоритмів (ГОСТ / ДСТУ 19.701-90) та UML-activity діаграм дій з вихідного коду C++. Ідеально підходить для оформлення студентських лабораторних робіт та звітів.

## 🚀 Швидкий запуск

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Збірка для продакшну
npm run build

# Перевірка коду (linter)
npm run lint
```

## ✨ Можливості

- **Миттєвий розбір C++ коду**:
  - `cin`, `cout` (ввід / вивід з автоматичним розпізнаванням підказок).
  - Умовні розгалуження: `if`, `if-else`, вкладені `if-else` (повна та скорочена форми).
  - Цикли: `while`, `do-while`, `for`.
  - Ігнорування констант (`const double PI = ...`) та директив препроцесора (`#include`, `using namespace std`).
- **Два формати діаграм**:
  - **Класична блок-схема (ДСТУ 19.701-90)**: овали (початок/кінець), паралелограми (ввід), документи/паралелограми (вивід), прямокутники (процес), ромби (розгалуження з мітками `+` та `-`).
  - **UML-activity діаграма діяльності**: початковий та кінцевий вузли, закруглені дії, ромби рішень, сторожові умови `[ x < 0 ]`, `[ else ]`.
- **Canva / Figma стиль навігації**:
  - Плавне панорамування полотна (перетягування мишкою або двома пальцями).
  - Масштабування (повзунок масштабу 20%–250%, кнопки `+` / `-`, коліщатко миші, швидке скидання на 100%).
- **Експорт високої чіткості**:
  - Експорт у векторний **SVG** (ідеально для вставки у Word / PDF без втрати якості).
  - Експорт у растровий **PNG** (High-DPI 2.5x для надчітких звітів та лабораторних).
  - Копіювання чистого SVG у буфер обміну в один клік.
- **Світла та темна теми**:
  - Підтримка світлої та темної теми з автовизначенням системних налаштувань та збереженням у `localStorage`.
  - Картки діаграм зберігають білий колір артборду для 100% збереження придатності до друку та академічних вимог.

## 📁 Структура проекту

```
src/
├── components/          # React компоненти UI
│   ├── CanvasControls.jsx  # Повзунок та кнопки масштабу
│   ├── CodeEditor.jsx      # Редактор коду з номерами рядків
│   ├── DiagramCard.jsx     # Артборд діаграми з кнопками дій
│   ├── Header.jsx          # Верхня панель та перемикач теми
│   ├── Toast.jsx           # Спливаючі сповіщення
│   └── ViewerPanel.jsx     # Робоче полотно з вкладками
├── constants/
│   └── defaultCode.js      # Початковий C++ код
├── parser/
│   └── cppParser.js        # Лексер та синтаксичний аналізатор AST
├── renderers/
│   ├── flowchartRenderer.js# Генератор SVG блок-схеми
│   └── umlRenderer.js      # Генератор SVG UML-activity діаграми
├── utils/
│   ├── exportUtils.js      # Експорт у SVG/PNG та буфер обміну
│   └── svgHelpers.js       # SVG примітиви та розрахунок BoundingBox
├── App.css                 # Повні стилі додатку (Light & Dark)
├── App.jsx                 # Головний компонент
└── main.jsx                # Вхідна точка React 19
```
